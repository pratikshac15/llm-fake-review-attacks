# LLM-Driven Adversarial Attacks on Fake-Review Detectors

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/pratikshac15/llm-fake-review-attacks/blob/main/llm_fake_review_attacks.ipynb)

Fake-review detectors are trained on yesterday's fakes. This project measures what happens when a bad actor uses an **LLM to rewrite fake reviews**. It compares that with classic adversarial attacks and tests whether **adversarial training** restores detection without flagging genuine customers.

## Why it matters
Classic adversarial attacks (FGSM/PGD on images, word substitution on text) add small, often unnatural perturbations. LLM attackers instead produce **fluent, meaning-preserving rewrites at near-zero cost**, which changes what a marketplace-integrity model has to be robust to.

## What's inside
| Step | Method |
|---|---|
| Data | 40K product reviews: 20K computer-generated fakes, 20K genuine ([Salminen et al., 2022](https://doi.org/10.1016/j.jretconser.2021.102771)) |
| Detectors | TF-IDF + logistic regression; fine-tuned DistilRoBERTa |
| Classic attack | Greedy word substitution (TextFooler-style), WordNet synonyms, ≤20% of words changed |
| LLM attack | Qwen2.5-1.5B-Instruct rewrites the review; *adaptive* mode queries the detector up to 3 times |
| Attack quality | Evasion rate, semantic similarity (MiniLM), fluency (GPT-2 perplexity), queries, transfer to TF-IDF |
| Defense | Adversarial training with 1,000 LLM rewrites; re-attacked with a fresh adaptive LLM attack |

## Results
<!-- RESULTS: filled in from results/results.json -->
300 fake reviews that the detector caught before any attack (DistilRoBERTa: 96.2% accuracy, 99.2% recall on clean fakes, PR-AUC 0.997).

| Attack | Evasion rate | Detector queries | Perplexity (original: 17) | Semantic similarity | Transfer to TF-IDF |
|---|---|---|---|---|---|
| Word substitution (≤20% of words) | 82.3% | 55.4 | 70.9 | 0.79 | 14.0% |
| LLM rewrite, 1 try | 91.7% | 1 | | | |
| LLM rewrite, adaptive (≤3 tries) | **100%** | **1.1** | **24.6** | 0.71 | **99.7%** |

**Takeaway:** LLM attacks are cheaper, more fluent and far more transferable than classic perturbation attacks. They read like real reviews and fool detectors they never queried.

**Defense: adversarial training with 1,000 LLM rewrites** (threshold re-tuned on validation to keep the false-positive rate at the original level)

| | Original detector | Hardened detector |
|---|---|---|
| False positives on genuine reviews | 6.8% | 6.7% |
| Recall on clean fakes | 99.2% | 98.5% |
| Recall on earlier LLM attacks | 0% | 95.7% |
| Fresh adaptive LLM attack evasion | 100% | 12%* |

\*Approximate: the attacker stopped retrying once it beat the default 0.5 threshold, so evasion against the tuned threshold may be slightly underestimated.

**Limitations and next steps:** the fake reviews were generated by an older (GPT-2-era) model; the defense was tested against the same LLM and prompt used for training. Next: test generalization to different LLMs and prompts, and to LLM-paraphrased genuine reviews.
